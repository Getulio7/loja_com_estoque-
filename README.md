# SISTEMA DE CONTROLE DE ESTOQUE E VENDAS

Esse projeto consiste em um sistema simples de controle de estoque e vendas desenvolvido em Python!

O sistema permite cadastrar produtos, controlar a quantidade disponível em estoque, registrar vendas e gerar um relatório final com informações importantes sobre o funcionamento da loja.
Cada produto cadastrado possui um nome e uma quantidade disponível, permitindo que o programa acompanhe automaticamente o estoque após cada venda realizada.

O sistema também verifica quais produtos estão com estoque baixo ou zerado, ajudando no controle de reposição de mercadorias. 
Durante o registro de vendas, o programa verifica se o produto possui unidades disponíveis, reduz a quantidade no estoque e armazena o valor da venda realizada. 
Além disso, o sistema calcula o faturamento total da loja, identifica o produto mais caro e o mais barato vendidos e contabiliza quantas vendas tiveram valor acima de R$100. 

Ao final da execução, é gerado um relatório completo contendo o estoque atualizado, o faturamento total, informações sobre as vendas, a data e horário do relatório.

* O projeto utiliza conceitos fundamentais da linguagem Python:
* funções, listas, dicionários, estruturas condicionais e estruturas de repetição.

Sendo uma aplicação prática voltada ao aprendizado de lógica de programação e organização de sistemas simples.
